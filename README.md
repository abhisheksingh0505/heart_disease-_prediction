# 🫀 Heart Disease Prediction Project

This project uses machine learning to predict the presence of heart disease based on patient data. The notebook processes the data, performs exploratory data analysis (EDA), and applies classification algorithms to achieve accurate predictions.

## 📂 Files Included

- `heart.csv` — The dataset containing heart disease-related medical records.
- `Task5.ipynb` — Jupyter Notebook containing data preprocessing, EDA, model training, and evaluation steps.
- `README.md` — Project overview and usage guide.

## 📊 Dataset Overview

The dataset (`heart.csv`) includes several medical attributes such as:
- `age`, `sex`, `cp` (chest pain type), `trestbps` (resting blood pressure), `chol` (cholesterol), etc.
- `target`: 1 indicates presence of heart disease, 0 indicates absence.

## 📌 Objective

To build a machine learning model that can accurately classify whether a person has heart disease based on medical attributes.

## 🚀 Steps Covered in the Notebook

1. **Loading and Understanding Data**
2. **Data Cleaning & Preprocessing**
3. **Model Training** (e.g.,  Decision Tree, Random Forest)
4. **Model Evaluation** using accuracy,  etc.
5. **Result Visualization**
